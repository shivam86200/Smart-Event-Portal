Project Phases

What the submission covers

Phase 1 - Source Code Management

Organize the repository, add meaningful commits, create release tags, and document the workflow in README.md.

Phase 2 - Docker

Use a clear Dockerfile, version the image as v1, v2, and v3, and present the visible UI changes in each release.

Phase 3 - Kubernetes

Describe deployments, services, scaling, rolling updates, and rollback behavior for production-safe releases.

Phase 4 - Jenkins

The Jenkins pipeline starts from a GitHub webhook, checks out code, builds and tests the app, creates and pushes the Docker image, deploys to Kubernetes, and verifies the release.
